# eGGs.gd

Small, opinionated software by one developer: web apps and PWAs, tools, libraries and games.
The projects live at [eggs.gd](https://eggs.gd); each one has its own repository and, when it has
a public face, its own site under `*.eggs.gd`.

- Found a vulnerability: [SECURITY.md](https://github.com/eggs-gd/.github/blob/main/SECURITY.md)
- Want to contribute: [CONTRIBUTING.md](https://github.com/eggs-gd/.github/blob/main/CONTRIBUTING.md)
